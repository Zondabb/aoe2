# Original game sound effects

`original/*.wav` contains a selected set of unmodified Age of Empires II HD
sound recordings. `manifest.json` maps gameplay event names to these files and
records each original filename, resource ID and SHA-256 checksum.

Rebuild and source mapping details: [audio export tool](../../tools/audio_export/README.md).

Audio includes Chinese and Teuton unit acknowledgments, original interface and
result cues, worker actions, combat, building selection, production and alarms.
The recordings retain their original ownership, as do the original sprite
resources already used by this project.
