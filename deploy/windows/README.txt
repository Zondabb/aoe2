AoE2 RTS - Windows x64

Extract the entire ZIP into a folder, then run aoe2.exe.
Keep aoe2.pck and libaoe_sim.windows.template_release.x86_64.dll beside
aoe2.exe. Godot does not need to be installed. Without the DLL the game
still runs, with slower unit movement simulation.
If included, aoe2.console.exe opens the game with a diagnostic console.

The Python AI service and multiplayer server are separate services and
are not bundled. Offline play uses the built-in game AI.
