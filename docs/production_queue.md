# 单位生产队列

选中己方城镇中心、兵营、靶场、马厩等生产建筑，重复点击单位训练按钮或对应快捷键即可排队。每座建筑最多容纳 15 个单位，包含正在训练的一项；同一建筑可混排其已解锁的兵种，各建筑独立生产。

面板显示从左到右的队列图标，最左侧高亮为当前任务，并显示训练百分比和队列数量。进度使用文明加成后的实际训练时间。点击任意队列图标可取消该项并全额退款；取消等待项不改变当前进度，取消当前项后下一项从零开始。

## 规则

- 入队时扣除该单位的全部资源，资源不足或队列已满时不能入队。
- 人口已满时仍可排队，当前任务显示“等待人口”并保留进度；房屋完工或人口腾出后自动继续。多个建筑同时生产也不会突破实际人口上限。
- 追加单位不会重置当前训练进度。每项完成后，只移除该项并自动训练下一项。
- 科技升级可以更新已排队的兵种，取消时仍按最初支付的资源退款。
- 正在升级时代或研究科技的建筑不能添加训练任务；已有训练队列时沿用原有规则，不能开始研究。
- 建筑被摧毁后停止生产并释放全部排队人口记录，不退还训练资源。
- 敌方队列不显示；只读或比赛结束状态不能修改队列。

## 联网

训练和取消都交给主机执行，主机验证归属、资源和队列状态。快照同步 `train_queue`、`train_queue_ids` 和 `train_progress`；取消命令为 `cancel_train`，携带 `building_id` 与 `queue_id`。每个任务有递增 ID，重复或延迟到达的取消命令不会误删下一项或重复退款。

Python 联机服务继续转发命令与快照，无需变更服务端规则。双方客户端需使用支持该队列字段的新版本。
