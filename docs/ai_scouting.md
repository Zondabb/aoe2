# 大地图上的 AI 探索与资源分配

默认地图的资源位于城镇中心视野以外，AI 开局先用侦察骑兵探索。Godot 本地 AI 和 Python 规则 AI 都使用公开地图边界、本方单位位置及当前可见的资源快照决定行动，不读取迷雾里的资源或敌方建筑位置。

侦察路线从本方城镇中心向地图中心方向开始，绕基地逐圈扩大。相邻探索圈间隔 24 个模拟距离单位，每圈增加路点数量，使相邻路点距离约为 24；路点限制在地图边界内。侦察兵到达路点后继续前往下一处，连续 8 秒没有有效前进时跳过阻塞位置。已看见的树木、矿石可用于避开当前路点；未知地形仍由现有寻路系统处理。

AI 的基地资源搜索距离扩大到 144，足以覆盖分散的近郊资源组。侦察兵发现矿石时，村民可能已经全部采集食物和木材。经济管理器每次决策最多调配一个空手的富余采集者到新发现、尚无人采集的资源种类；不打断运输、建造或战斗，不带走原资源种类的最后一个采集者，也不会覆盖当前决策已分配的建造命令。

村民已经收到的采集命令保留最后看见的位置。Python AI 记录此前确实观察过的资源编号及种类，用于统计已有分工；资源暂时离开视野不会被当作耗尽。这份记忆不包含隐藏库存或新目标坐标，新的采集目标始终来自当前可见快照。

已知四类资源且进入进攻阶段后，侦察兵会探索地图中心和基地对面的区域，为军队寻找敌人。这些位置由公开地图几何推算，不能直接取得未被观察到的敌方城镇中心位置。自定义地图没有侦察兵且没有可见资源时，会使用一个闲置村民暂时探索；已有采集、建造和攻击命令受到保护。

验证：

```powershell
godot --headless --path . --script res://tests/run_ai_scouting.gd
Push-Location ai_service_python
python -m pytest tests/test_scout_manager.py
Pop-Location
```

Godot 测试运行真实默认地图、迷雾、寻路、训练、建设与采集循环，不额外发放资源或缩短生产时间。在固定种子布局下，AI 约 90 秒发现全部四类资源，约 156 秒完成四类资源的首次运输入库。建造工人优先从闲置或空手采集者中选择，保留原有建设、运输、移动、战斗和当前决策已经分配的命令。Python 测试覆盖不可见目标不会影响路线、公开矩形地图边界、路点推进、阻塞恢复、村民临时探索、已有命令保护与矿工在迷雾中继续原采集路线。
