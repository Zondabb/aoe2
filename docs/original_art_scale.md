# 单位与建筑显示比例

导入的原版 SLP 图像保留像素尺寸，人物、骑兵、攻城器械、建筑和资源已经包含原版的大小关系。游戏画面统一按 **1.2 倍**显示单位、建筑和资源，不再给人物单独放大到 2.2 倍、资源放大到 2.0 倍。人物现在是此前显示尺寸的约 55%，各兵种之间的原版大小差异也得到保留。

`SpriteCatalog.ORIGINAL_ART_PIXEL_SCALE_2D` 是共同缩放参数。建筑显示不再根据裁剪后的图片宽度单独改变缩放，避免屋顶、阴影和不同文明、时代图像的裁剪尺寸影响人物与建筑比例。角色动画每帧仍根据原版热点定位脚下位置，行走、攻击、采集、建造和死亡使用相同缩放。

例如，原版村民待机图帧为 25×44 像素，黑暗时代城镇中心的合成帧约为 394×227 像素。两者共同乘以 1.2，保持原始图片中的人物与建筑关系。图帧包含透明边缘和阴影，因而不会把帧尺寸当作建筑实际占地。

这项调整改变显示尺寸；单位的碰撞半径、移动速度、攻击距离、建筑逻辑占地及资源碰撞范围继续由已有游戏规则确定。选中圆圈仍以碰撞半径定位；血条和遮挡轮廓跟随缩小后的角色图像。

验证命令：

```powershell
godot --headless --path . --script res://tests/run_original_art_scale.gd
godot --path . --script res://tests/run_original_art_scale.gd -- --render
```

测试使用实际单位、建筑场景，覆盖两个文明、四个时代、所有已导入单位的动画、左右镜像热点、升级刷新和选中状态。可视化预览保存到 `.godot/original-art-scale.png`，展示村民待机、行走、伐木、采矿及民兵攻击姿态与城镇中心、兵营的大小关系。
