# 玩家操作、选取与编队

适用于当前 2D 对局、战斗演练和联机本地玩家。基本选取与数字分组参照 [AoE II 官方操作教程](https://www.ageofempires.com/learn-to-play/control-resources-aoe2/) 和 [控制组教程](https://www.ageofempires.com/learn-to-play/match-goals-aoe2/)。

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 选取单位、建筑；敌军和资源可单独查看 |
| 左键拖动 | 白色框选，可向任意方向拖动，只选择己方单位 |
| Shift + 单击 | 加入选择；再点已选单位会移除 |
| Shift + 框选 | 将框内己方单位加入当前选择 |
| 双击己方单位 | 选取当前可见游戏区域内的同类单位 |
| Shift + 双击 | 将当前画面内的该类单位加入选择 |
| 右键地面 | 移动；点击处播放红色收拢动画 |
| 右键敌人 / 资源 / 未完成建筑 | 攻击 / 村民采集 / 村民建造 |
| Ctrl + 0–9 | 将当前选择保存为数字编队，替换该组 |
| Shift + 0–9（或 Ctrl + Shift + 数字） | 将当前选择加入已有编队 |
| 0–9 | 选取对应编队 |
| 连按两次相同数字 | 选取编队并将镜头移到编队中心 |
| Alt + 数字 | 将镜头移到编队，保留当前选择 |
| I / O / P / L | 横队 / 方阵 / 疏散 / 两翼 |

选择至少两个己方单位时，单位指令页显示四个原版队形图标，当前队形以金色边框标识。村民进入建造菜单后，字母快捷键仍属于建筑菜单。正在输入文字时不触发上述快捷键。

建立编队后，顶部显示组号和存活数量，单击可选取该组。选中单位脚边显示所属组号。死亡、删除和转换阵营会清理成员；空组不会清空当前选择。单位与建筑分别组队，敌军和资源不能编入己方指令组。组号是当前本地对局的输入状态，不跨新对局或读档保存。

选取圈采用加大的白色椭圆和深色轮廓，仍绘制在人物下方。旧地图中的碰撞半径与显示尺寸分开处理，避免旧版步兵出现过大的圆圈。

群体移动依据行进方向分配独立站位，横队将近战放在前方、远程在后方；方阵优先保护内侧单位，疏散增大间距，两翼分成左右两组。混合兵种按组内最低移动速度行进，单独下令后恢复自身速度。行进途中切换队形会保留当前目的地中心；静止时则在当前位置重排。各单位仍使用现有寻路与避障系统通过障碍，再到达各自站位。

联机使用现有逐单位移动指令传递站位，并附带可选的 `formation_speed`。主机检查归属、坐标和速度上限，普通移动指令仍兼容原有协议。

## 验证

```powershell
& $godot --headless --path . --script res://tests/run_player_controls.gd
& $godot --headless --path . --script res://tests/run_selection_lifetime.gd
& $godot --path . --script res://tests/render_player_controls.gd --rendering-method gl_compatibility
```

`run_player_controls.gd` 覆盖真实 Viewport 鼠标/键盘事件、GUI 消费释放事件、文字焦点、同类选择范围、数字组、单位死亡/阵营变化、队形站位、混合速度和主机验证。GPU 检查会输出 `.godot/controls-{line,box,staggered,flank,move}.png`，比较实际像素确认选取圈、缩放和移动动画。
